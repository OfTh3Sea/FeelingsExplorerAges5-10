# 🧭 Feelings Explorer
### Emotional Check-in Tool for Ages 5–10

> An interactive, read-friendly emotional check-in experience built for early elementary children. Features flip cards that teach what emotions mean, multi-select feelings with intensity sliders, and a free finger-drawing canvas for expressing what words cannot always capture.

---

## 📖 Overview

**Feelings Explorer** bridges the gap between the pre-reader tools designed for toddlers and the complex emotional landscape of adolescence. Children ages 5–10 are developing real emotional vocabulary — they can read, they understand cause and effect, they experience layered and sometimes contradictory feelings — but they still need age-appropriate language, visual support, and playful interaction design to engage honestly.

The tool teaches emotional literacy alongside the check-in itself. Every emotion card can be flipped to reveal a child-friendly definition and a relatable real-life example. Children can select multiple emotions at once, rate the intensity of each on a color-matched slider, and draw a picture to express what their words have not quite captured.

Designed for **elementary classrooms, school counseling offices, pediatric clinics, and home use** — and built to be used independently by children who are just learning to read.

## ✨ Features

### 🃏 Flip Card Emotion System
- **First tap:** card flips to reveal the emotion's name, a child-friendly definition, and a relatable example sentence
- **Second tap:** card is selected — a color-matched border glow confirms the choice
- 3D flip animation makes the learning moment feel engaging rather than instructional
- Cards retain state if the child navigates back

### 📊 Intensity Sliders
- Every selected emotion reveals a 1–10 sliding scale below its card
- Slider track and thumb are color-coded to match the emotion
- Labeled "A little → A lot!" for age-appropriate framing
- Multiple emotions can be selected and rated simultaneously
- Summary screen displays emotions sorted by intensity — strongest feeling first

### 🎭 Two-Tier Emotion Library

**8 core feelings shown by default:**
Happy · Excited · Proud · Calm · Worried · Frustrated · Sad · Scared

**10 more revealed with "More feelings" button:**
Grateful · Silly · Lonely · Confused · Bored · Jealous · Embarrassed · Disappointed · Nervous · Hopeful

Every emotion includes a child-facing definition and example sentence written at a 1st–3rd grade reading level.

### 🎨 Free-Draw Canvas
- Full finger or stylus drawing on a touch-responsive canvas
- 10 colors including white for correction
- 4 brush sizes (S, M, L, XL) sized for small hands
- Dedicated eraser mode, undo (up to 20 steps), and clear all
- Drawing is entirely optional
- Drawing is captured and displayed on the summary screen

### 📋 Summary Screen
- All selected emotions displayed as color-coded chips
- Horizontal bar chart showing each emotion's intensity, sorted strongest first
- Drawing preview if one was created
- Confetti on arrival

## 🧠 Designed Around Social-Emotional Learning

Feelings Explorer is built around core SEL principles for early childhood:

| Principle | How it works in the tool |
|-----------|--------------------------|
| **Emotional vocabulary building** | Every card teaches a definition and real-world example |
| **Validation of complexity** | Multi-select allows children to hold two feelings at once |
| **Self-regulation support** | Rating intensity builds metacognitive awareness |
| **Non-verbal expression** | Drawing canvas gives an outlet when words are not enough |
| **No wrong answers** | The UI never rejects or corrects an emotional choice |

## 🚀 Getting Started

### Requirements
- Any modern browser (Chrome, Safari, Firefox, Edge)

```bash
git clone https://github.com/OfTh3Sea/feelings-explorer.git
cd feelings-explorer
open feelings-explorer.html
```

Or download `feelings-explorer.html` and open it directly in any browser.

## 💾 Privacy

- No data is stored — Feelings Explorer uses no `localStorage`, cookies, or backend
- Each session is completely fresh; nothing persists between visits
- No accounts, logins, or tracking of any kind
- Suitable for school and clinical settings with no data privacy considerations beyond the device

## ♿ Accessibility

- Large touch targets (minimum 160px card height) for small hands
- Color is never the sole differentiator — each emotion has a distinct emoji, label, and color
- High-contrast text throughout
- Progress bar provides spatial orientation in the flow
- Back button available on all screens after the welcome screen
- No time-limited interactions anywhere in the flow
